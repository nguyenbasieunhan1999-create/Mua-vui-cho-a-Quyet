# GĐ2.5 — UI/UX: Sitemap, Wireframe, Component tree

## 1. Sitemap

```
Người chơi                                         Admin
/                Home: nhập nickname                /admin/login
/lobby           Tạo phòng · Nhập mã                /admin/rules            Dashboard luật (tab theo nhóm)
/r/{code}        Phòng chờ ⇄ Bàn chơi ⇄ Kết quả     /admin/rules/diff       Diff draft vs ACTIVE
/rules           Xem luật đang áp dụng (read-only)  /admin/rules/versions   Lịch sử version · Rollback
/rules/v/{v}     Luật của một version (snapshot)    /admin/audit            Audit log
/history/{sid}   Bảng điểm phiên + danh sách ván
/replay/{gid}    Xem lại ván (sau khi kết thúc)
```
Luồng chính: Home → nickname → Lobby → Phòng (ready) → Bàn → Kết quả/Scoreboard → Sẵn sàng ván tiếp.
Luồng Admin: Login → Rules Dashboard → Validate → Diff → Publish (xác nhận) → Audit.

## 4. Các màn hình còn lại (tóm tắt)

| Màn | Nội dung chính |
|---|---|
| Home | Ô nickname (2–20 ký tự, kiểm tra ngay khi nhập), nút "Vào chơi"; nếu đã có token thì "Tiếp tục với tên X" |
| Lobby | "Tạo phòng" · "Nhập mã phòng" · danh sách phòng đã chơi gần đây (của mình) |
| Phòng chờ | 4 ghế (trống/đã ngồi/ready), link mời + nút copy, nút Ready, version luật + link xem, chủ phòng có nút Đóng phòng / Khởi động lại phiên |
| Kết quả ván | Thứ hạng, nhãn (Cóng, Tới trắng, Đút mù, Thoát), bảng transfer có giải thích ("D trả A 200 – cóng"), bài còn lại của mọi người, tổng phiên, nút "Sẵn sàng ván tiếp" |
| Xem luật | Nhóm giống Excel; mỗi dòng: Excel ID, tên, giá trị hiện hành, tooltip mô tả (cột D) |
| Replay | Thanh thời gian theo seq, bước tới/lui, hiện bài cả 4 người |
| Admin Rules Dashboard | Tab theo nhóm Excel; toggle/select/number/bảng ma trận/danh sách kéo thả; mỗi field có badge Excel ID, tooltip mô tả D, nút "về mặc định"; panel cảnh báo validate cố định bên phải; thanh trạng thái draft (lock_version, người sửa cuối) |
| Admin Publish | Modal: diff tóm tắt, danh sách warning cần tick, ô ghi chú bắt buộc, ghi rõ "Áp dụng từ ván tiếp theo của mọi phòng" |

## 5. Trạng thái đặc biệt

| Trạng thái | Cách hiển thị |
|---|---|
| Loading | Skeleton cho bàn và ghế; không hiện bài cho tới khi có snapshot |
| Mất kết nối của mình | Banner vàng "Đang kết nối lại…" (backoff 0.5s → 8s), khóa nút Đánh/Bỏ lượt; kết nối lại xong thì nạp snapshot |
| Đối thủ mất kết nối | Biểu tượng ⟳ + đồng hồ đếm giữ ghế |
| Sắp hết giờ | Thanh timer đổi màu ở 10s và 5s, rung nhẹ trên mobile (nếu được phép) |
| Hết giờ | Toast "Bạn đã mất lượt" / "Hệ thống tự đánh 3♣" |
| Nước bị từ chối | Lá rung lại, thông báo theo error code bằng tiếng Việt (vd `CANNOT_BEAT` → "Bài chưa đủ lớn để chặn") |
| Luật mới được publish | Toast "Luật v13 sẽ áp dụng từ ván sau" + link diff |
| Server khởi động lại | Banner "Ván đã được khôi phục, lượt hiện tại được cấp lại thời gian" |

## 6. Component tree (React)

```
App (Router, QueryClientProvider, AuthProvider)
├─ PlayerShell
│  ├─ HomePage ─ NicknameForm
│  ├─ LobbyPage ─ CreateRoomButton · JoinByCodeForm · RecentRooms
│  ├─ RoomPage  (useRoomSocket: WS + reducer state + reconnect)
│  │  ├─ RoomHeader (RoomCode, RuleVersionBadge, SessionScoreButton)
│  │  ├─ WaitingRoom ─ SeatCard×4 · InviteLink · ReadyButton · OwnerControls
│  │  ├─ GameTable
│  │  │  ├─ OpponentSeat×3 (Avatar, CardBack count, Status, HoldTimer)
│  │  │  ├─ TrickArea (TopPlay, TrickPassList)
│  │  │  ├─ TurnTimer
│  │  │  ├─ MyHand (Card×n, SortToggle, selection state)
│  │  │  └─ ActionBar (PassButton, PlayButton)
│  │  ├─ GameResultModal (RankingTable, TransferList, RevealedHands)
│  │  └─ ConnectionBanner · Toasts
│  ├─ RulesPage ─ RuleGroup ─ RuleRow
│  ├─ HistoryPage ─ ScoreBoard · GameList
│  └─ ReplayPage ─ ReplayTimeline · GameTable(readOnly)
└─ AdminShell (requireAdmin)
   ├─ AdminLoginPage
   ├─ RulesDashboard ─ RuleGroupTabs ─ RuleField(Toggle|Select|Number|Matrix|OrderedList) · ValidationPanel · DraftStatusBar
   ├─ RulesDiffPage · PublishDialog
   ├─ VersionsPage · RollbackDialog
   └─ AuditPage
```
Thư viện: React 18, React Router, TanStack Query (REST), state game giữ bằng `useReducer` (server là nguồn chân lý), CSS Modules + biến CSS; kéo xếp bài bằng `@dnd-kit`. Hỗ trợ bàn phím/aria cho lá bài và nút, độ tương phản AA.
